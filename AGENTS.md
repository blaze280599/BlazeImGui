# Agent instructions

* **Adding this menu to another project?** Follow [INTEGRATION.md](INTEGRATION.md) step by step. The C#
  library ships as NuGet packages (`BlazeImGui.Overlay` for a standalone overlay, `BlazeImGui` alone for a host
  that owns its ImGui context): `tools/pack.ps1 -Into <project>/packages` puts both in that project's committed
  local feed. Never copy `src/BlazeImGui` into a project or reference this folder from
  another repository, so every project builds on its own from a fresh clone.
* **Changing the library itself?** Code lives in `src/BlazeImGui` (no ClickableTransparentOverlay types there:
  hosts that own their context use it alone) and `src/BlazeImGui.Overlay` (`BlazeOverlay`, `OverlayOptions`,
  `WindowTarget`); `samples/BlazeImGui.Demo/DemoOverlay.cs` exercises every widget. Build with
  `dotnet build BlazeImGui.sln`. Bump `<Version>` in `src/Directory.Build.props` before packing a release (NuGet
  caches by version); each project's `PACKAGE.md` is its package's README.
* Widgets read colors only from `Theme.Colors` tokens and pack them with `Theme.U32` (so theme switches and
  fades apply); animated state uses `Anim` keyed by ImGui IDs. Keep new widgets to that pattern and to the
  label-above layout (`Ui.Row`: label on its own line, control at `Ui.ControlWidth` under it); descriptions go
  through `Ui.About` so they show under ABOUT in the status column.
* Never pass dynamic strings to `ImGui.Text`/`TextColored`/`TextWrapped` (printf formats); use
  `ImGui.TextUnformatted`, `Ui.Text` or `Ui.TextWrapped`.
* Visual check: `dotnet run --project samples/BlazeImGui.Demo -- --backdrop --page "Controls"` (add `--theme light`).
* `Icons.g.cs` is generated by `tools/generate-icons.ps1`; don't edit it by hand.
* **C++ port** (`cpp/BlazeImGui`, namespace `Blaze`): same look and widgets for native Dear ImGui 1.92+ hosts; see
  [cpp/README.md](cpp/README.md). Keep it in step with the C# library when changing widgets or tokens.
  `blaze_icons.h` and `blaze_font_data.cpp` are generated by `tools/generate-cpp.ps1`. Projects get it as a
  package from `tools/pack-cpp.ps1 -Into <project>/external/blazeimgui` (never a copy of `cpp/BlazeImGui`); bump
  `BLAZE_IMGUI_VERSION` in `blaze_imgui.h` for a release, and keep `cpp/package/` in step with the file list.
  Visual check: build `cpp/samples/demo_dx11.cpp` and run it with `--screenshot out.bmp`.
* **Rust port** (`rust/blaze-imgui`, crate `blaze_imgui` on `dear-imgui-rs` 0.21): same look and widgets; see
  [rust/README.md](rust/README.md). Keep it in step with the C# library too. `src/icons.rs` and `fonts/` come from
  `tools/generate-rust.ps1`. Build with `cargo build --example demo` in `rust/blaze-imgui`; visual check:
  `cargo run --example demo -- --page "Controls" --screenshot out.bmp` (add `--theme dark`). Projects depend on it
  by git with a `rust-v<version>` tag (never a copy or a path dependency); for a release bump `version` in its
  `Cargo.toml`, commit, then tag and push that commit.
