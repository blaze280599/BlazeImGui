# Agent instructions

* **Adding this menu to another project?** Follow [INTEGRATION.md](INTEGRATION.md) step by step. Copy
  `src/BlazeImGui` into that project's repository and reference the copy; never reference this folder from
  another repository, so every project builds on its own from a fresh clone.
* **Changing the library itself?** Code lives in `src/BlazeImGui`; `samples/BlazeImGui.Demo/DemoOverlay.cs`
  exercises every widget. Build with `dotnet build BlazeImGui.sln`.
* Widgets read colors only from `Theme.Colors` tokens and pack them with `Theme.U32` (so theme switches and
  fades apply); animated state uses `Anim` keyed by ImGui IDs. Keep new widgets to that pattern and to the
  label-left / control-right row layout (`Ui.Row`).
* Never pass dynamic strings to `ImGui.Text`/`TextColored`/`TextWrapped` (printf formats); use
  `ImGui.TextUnformatted`, `Ui.Text` or `Ui.TextWrapped`.
* Visual check: `dotnet run --project samples/BlazeImGui.Demo -- --backdrop --page "Controls"` (add `--theme light`).
* `Icons.g.cs` is generated by `tools/generate-icons.ps1`; don't edit it by hand.
* **C++ port** (`cpp/BlazeImGui`, namespace `Blaze`): same look and widgets for native Dear ImGui 1.92+ hosts; see
  [cpp/README.md](cpp/README.md). Keep it in step with the C# library when changing widgets or tokens.
  `blaze_icons.h` and `blaze_font_data.cpp` are generated by `tools/generate-cpp.ps1`.
  Visual check: build `cpp/samples/demo_dx11.cpp` and run it with `--screenshot out.bmp`.
